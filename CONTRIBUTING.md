# Contributing

Thanks for your interest in this project.

This repository contains a small Python game primarily intended for geocaching puzzles.  
Contributions are welcome, especially improvements related to clarity, stability, or configurability.

## How to Contribute

- Fork the repository
- Create a focused branch
- Open a pull request with a short description

## Guidelines

- Keep the code simple and readable
- Avoid unnecessary dependencies
- Prefer clarity over clever solutions

If you are unsure about a change, feel free to open an issue first.
